### Definitions

**CONTENT**  
Existing supported fields/content only. Examples: hours, copy, image, Wi-Fi guest credentials, contact info.

**THEME**  
Visual system or structure. Examples: typography, spacing, layout, cards, navigation, brand treatment.

**FEATURE**  
New guest-facing capability or module.

**INTEGRATION**  
Connection to PMS, booking, payment, membership, CRM, LINE, API, or other external systems.
